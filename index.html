হোম স্ক্রিন থেকে এক ট্যাপে খুলুন, অফলাইনেও কাজ করবে।

📲 অ্যাপ হিসেবে ইনস্টল করার নিয়ম

🤖 Android (Chrome)

  1. উপরে ডান দিকের ⋮ মেনুতে চাপ দিন
  2. "Install app" বা "Add to Home screen" বেছে নিন
  3. Install চাপুন — হোম স্ক্রিনে আইকন এসে যাবে

💻 Windows / Mac / Linux (Chrome)

  1. অ্যাড্রেস বারের ডান পাশে ⤓ Install আইকনে ক্লিক করুন
  2. অথবা ⋮ মেনু → "Install Meal Khata"
  3. পপ-আপে Install চাপুন

🍎 iPhone / iPad (Safari)

  1. নিচের Share (⬆️) বাটনে চাপ দিন
  2. "Add to Home Screen" বেছে নিন
  3. Add চাপুন

নোট: iOS-এ ইনস্টল করতে Safari ব্রাউজার লাগবে, Chrome-এ অপশনটি থাকে না।

ইনস্টল করার জন্য সাইটটি HTTPS-এ খোলা থাকতে হয় (যেমন GitHub Pages লিংক), অথবা ব্রাউজারে localhost হিসেবে চলতে হয়। সরাসরি ফাইল খুললে (file://) ইনস্টল বাটন আসবে না।
